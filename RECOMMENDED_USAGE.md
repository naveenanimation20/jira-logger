## 🚀 RECOMMENDED: Quick Bug Report (30 seconds)

This is the **best way** to use the extension:

### **How to Use:**

1. **Navigate to the page with the bug**

2. **Click extension icon** → **"Quick Bug Report"**

3. **Extension auto-captures:**
   - ✅ Screenshot
   - ✅ URL
   - ✅ Browser info
   - ✅ Timestamp
   - ✅ Console errors (if any)

4. **You just fill in:**
   - Bug summary
   - Actual behavior
   - (Optional) Expected behavior

5. **Click "Create Jira Issue"**

6. **Done in 30 seconds!** ✅

---

## ✍️ Manual Steps (Type them yourself)

If you need reproduction steps, just type them manually in the form. It's actually faster and more reliable than trying to record:

### Example:
```
Steps:
1. Go to login page
2. Enter username
3. Click login button
4. Error appears
```

**Time: ~20 seconds to type**  
**Result: Clear, accurate steps**  
**No technical issues!**

## ⚠️ Recording Feature - Advanced (Has Issues)

The recording feature has some limitations due to Chrome's popup behavior:

### **Known Issues:**
- Popup closes when you click on page (Chrome limitation)
- Causes errors during recording
- Complex to maintain state
- Can be unreliable

### **When Recording Might Work:**
- Simple pages (google.com)
- Very short recordings (3-5 clicks)
- If you keep popup visible somehow

### **Better Alternative:**
- Use Quick Bug Report
- Type steps manually
- Much more reliable!

## 💡 Pro Tips

### **Make Summaries Clear:**
```
❌ Bad: "Login broken"
✅ Good: "Login fails with 'Invalid credentials' error when using SSO"
```

### **Type Steps Clearly:**
```
1. Navigate to /login
2. Click "Sign in with Google"
3. Complete Google auth
4. Redirected to error page instead of dashboard
```

### **Use Priorities:**
- Critical: System down, data loss
- High: Major feature broken  
- Medium: Feature partially working
- Low: Minor cosmetic issue
