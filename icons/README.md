# Extension Icons

This directory needs 4 PNG icon files for the Chrome extension:

## Required Files

- **icon16.png** - 16×16 pixels (toolbar icon)
- **icon32.png** - 32×32 pixels (toolbar retina)
- **icon48.png** - 48×48 pixels (extension manager)
- **icon128.png** - 128×128 pixels (Chrome Web Store)

## Temporary Solution

The extension will work without these files - Chrome will just show a default icon. For testing, this is fine!

## Design Guidelines

When you create icons, use the extension's color scheme:
- Primary: Teal gradient (#0d9488 to #06b6d4)
- Accent: Purple (#7c3aed)
- Style: Modern, flat, simple

## Icon Ideas

1. Bug + Test Tube (represents QA testing)
2. Bug + Lightning (represents quick logging)
3. Bug + Checkmark (represents logged bug)
4. Stylized "JQL" letters

## Quick Creation Tools

- **Canva**: Easy, templates available
- **Figma**: Professional, vector-based
- **Pixlr**: Online, no install needed
- **GIMP**: Free Photoshop alternative
